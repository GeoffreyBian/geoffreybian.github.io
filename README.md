# geoffreybian.github.io

Source for [geoffreybian.github.io](https://geoffreybian.github.io), built with
[Jekyll](https://jekyllrb.com/) and the
[al-folio](https://github.com/alshedivat/al-folio) theme, hosted on GitHub Pages.

## Layout

```
_pages/          about (/), projects, cv
_projects/       one file per project card
_news/           short dated announcements on the about page
_bibliography/   papers.bib, rendered on the about page
assets/          images, PDFs, compiled css/js
portfolio.html   encrypted stocks dashboard   -> /portfolio/
study.html       encrypted term board         -> /study/
dashboards.html  index of the three           -> /dashboards/
```

## The dashboards

`/portfolio/` and `/study/` are generated, not hand-written. Each ships **no
data at all**: the page fetches an AES-256-GCM blob from an orphan branch of
this repo and decrypts it in the browser after a passphrase, so the figures
never sit at a fetchable URL in the clear. The blob is force-pushed as a single
commit each time, which is what makes rotating the passphrase meaningful —
ciphertext under the old key stops existing rather than staying reachable in
history.

Both pages are written by scripts in their own repos. **Edit the templates
there, not the generated file here:**

| Page | Generated by | Data branch |
|---|---|---|
| `/portfolio/` | `scripts/publish_web_dashboard.py` in the stocks repo | `portfolio-data` |
| `/study/` | `publish_web.py` in [`GeoffreyBian/study`](https://github.com/GeoffreyBian/study) | `study-data` |

`/train/` is a separate public project site at
[`GeoffreyBian/train`](https://github.com/GeoffreyBian/train).

Both generated pages are `noindex` and `sitemap: false`. Encryption is not a
reason to be in anyone's search index.

## Running it locally

```bash
bundle install
bundle exec jekyll serve   # http://localhost:4000
```

or `docker compose up`.
